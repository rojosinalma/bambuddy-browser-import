Bambuddy Import
Browser import — connect to your Bambuddy instance
Connection
The base URL of your Bambuddy instance — no trailing slash needed. Use http:// for local network addresses.
Required permissions: Manage Library + Allow cloud access. See the setup guide below.
Behaviour
Parallel imports
How many plates Bambuddy downloads at the same time when several are selected.
Notify when an import finishes
Imports keep running after the popup closes; a desktop notification tells you when they are done. Click it to open the folder in Bambuddy.
Model cache (seconds)
A model page is resolved as soon as it loads and kept this long, so the popup opens instantly. Lower it if profile lists look stale.
Show "Open in Bambuddy" after import
Display a button that opens the target folder in Bambuddy's File Manager after an import.
How to create an API key
1
Open your Bambuddy instance and go to Settings → API Keys.
2
Click Create API Key. Give it a name (e.g. "Browser Import").
3
Enable Manage Library — this covers saving and importing models, including MakerWorld imports.
4
Also enable Allow cloud access — required for Bambuddy to use your Bambu Cloud token when downloading from MakerWorld.
5
Make sure the Bambu Cloud account is linked under Settings → Bambu Cloud. The same account's bearer token is used for all MakerWorld downloads.
6
Copy the key (shown only once) and paste it above. Save.
Usage tips
If you click on a specific print profile on MakerWorld before opening the extension, the URL will contain #profileId-XXXXX and that profile will be pre-selected automatically.
Click several profile cards (or All) to import them in one go, and pick the target library folder below the list. Importing a plate that is already in your library is safe — Bambuddy reports it as existing.
Bambu Cloud tokens expire after ~90 days. If imports start failing with "requires a Bambu Cloud login", re-authenticate under Settings → Bambu Cloud in Bambuddy.
